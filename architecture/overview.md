# CML Architecture Overview

## Purpose

CML (Cognitive Management Layer) is the safety, governance, alignment, and policy engine of Sorabbyngo OS.

Every intelligent component executes through CML before interacting with the operating system, hardware, networks, users, or external services.

Rather than being another AI model, CML acts as the operating system's constitutional layer. It determines whether an action is permitted, how it should be executed, and how it should be recorded.

---

## Core Responsibilities

- Safety enforcement
- Policy evaluation
- Permission management
- User consent verification
- Risk assessment
- Alignment with system objectives
- Action auditing
- Regulatory compliance
- Secure execution approval
