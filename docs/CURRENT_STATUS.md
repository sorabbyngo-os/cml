# Current Status

## Current Focus

CML has been defined as the governance layer of Sorabbyngo OS.

The architecture establishes:

- Safety evaluation
- Policy enforcement
- Permission management
- Alignment
- Auditing
- Action governance

Implementation will provide shared services used by Chameha, Byngox, HAL, Byngonet, Novela, and future Sorabbyngo applications.

No subsystem is expected to execute privileged actions without CML approval.
